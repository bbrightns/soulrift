## Priority Issues

**[P1] "BOOBY FOREST" breaks arcane register** — First dungeon name is a tone-breaker. Fix: rename to something world-consistent (Mirewood, The Wailing Glade, Feral Threshold).

**[P1] Clear All Slots — no confirmation** — Destructive irreversible action with no guardrail. Fix: add dialog confirm using existing .modal-overlay pattern.

**[P2] "Order" nav label is opaque** — Players won't find the spell sequence screen. Fix: rename or add contextual empty-state bridge on Battle screen when blueprint is empty.

**[P2] No post-onboarding guidance** — Players land on Battle with empty blueprint and no orientation. Fix: empty-state on Battle when blueprint is empty, or dim Enter Battle until one slot is filled.
